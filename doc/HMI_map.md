# Карта регистров панели оператора (Modbus TCP)

ЕФБШ-649.01-АТХ, ЛПЗС-5 ССЦ "Золотой початок". Сгенерировано `gen/gen_hmi_map.py` из исходников — не редактировать вручную.

Контроллер TM241CE40T — Modbus TCP сервер, порт 502, регистры хранения (holding, функции 3/6/16) соответствуют `%MW` с тем же номером. Все поля 16-битные. Команды (`wCmd`) — импульсные биты: панель устанавливает бит, контроллер сбрасывает после обработки (кроме помеченных «пока нажато»/режимов). Уставки можно и читать, и записывать: контроллер сохраняет их в RETAIN и ограничивает диапазон.
