# Бумажные боты V2 (только данные, без ключей и ордеров)

Два процесса для круглосуточной бумажной проверки. Ключи не нужны, ордера не отправляются.

Результаты бумажных тестов — [RESULTS.md](RESULTS.md).

| Файл | Что делает |
|---|---|
| `latbot.js` | Латентный арбитраж BTC/ETH Up/Down 5m и 15m. Правило `latarb_v1` (заморожено 2026-11-05 01:20 UTC): скачок Binance за 1 с больше 2 б.п. → виртуальная покупка стороны скачка по лучшему ask CLOB, каким он был через 150 мс по серверному времени. Размер ≤ 100 акций, комиссия 0,07·p·(1−p). Оценка: середина через 10 с, выход по bid через 10 с с двумя комиссиями, итог окна. ETH — контроль. |
| `lp_universe.js` | Вселенная для LP: рынки с наградами ≥ $5 в день, без спорта, до конца ≥ 3 дней, середина 0,10–0,90. Берёт 300 рынков с лучшей ожидаемой отдачей на капитал. |
| `lp_paper.js` | Бумажный LP с перекотировкой раз в 10 с. Варианты `g` и `h`. Исполнения: сделки RTDS по нашей цене или сквозь неё, плюс пересечение стакана. Награды считаются по формуле Polymarket раз за опрос, доля — пессимистичная и агрессивная. |
| `report_lat.js`, `report_lp.js` | Сводки. |

Запуск (нужен Node ≥ 22):

```bash
./run.sh start    # запустить оба процесса
./run.sh report   # сводка
./run.sh stop     # остановить
```

Данные пишутся в `out/` (сделки латентного бота) и `lpout/` (состояние и журналы LP).
Перезапуск продолжает с сохранённого состояния.
Перекотировка LP по умолчанию раз в 10 с; `POLL_MS=3000 ./run.sh start` — раз в 3 с (в тестах лучше, но запросов к API больше).

Критерии зачёта (заранее заданы):

- Латентный арбитраж: ≥ 2000 бумажных сделок по BTC. Перевес через 10 с > +3¢ на акцию при t > 3,
  выход через 10 с > 0, итог окна > 0.
- LP: ≥ 24 ч, затем подтверждение ещё 24 ч на свежей вселенной. Итог (награды по пессимистичной доле
  плюс переоценка) > 0, ни один рынок не даёт больше 25% итога.

## Критерии теста
`latarb_v2.md` — план 24/7-фазы, зафиксирован до новых данных. Основной рынок — BTC 5m, метрика — выход по bid через 10 с с двумя комиссиями. Сертификат: ≥ 2000 сделок BTC (из них ≥ 1000 BTC 5m), p < 0,01, итог окна > 0, ни один день не даёт > 50 % P&L, ≥ 70 % полных дней в плюсе. `latarb_v1.md` и `lp_v1.md` — предыдущие планы.
