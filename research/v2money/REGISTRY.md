## Правила скептика (каждое уже ловило ложный результат)

1. **RTDS `activity/trades` даёт запись на каждую сторону сделки:** одну на тейкера (средняя цена; в рынках
   с комиссией только у неё есть поле `fee`) и по одной на каждый задетый ордер мейкера. Считать «сделки»
   и объём можно только после склейки по `transactionHash`. Мейкер v1 (H6) из-за этого завысил итог в ~4 раза.
2. **Сторона важна:** тейкер-продажа бьёт только по bid. Исполнение «цена дошла до нашей» без стороны — ошибка.
3. **Пассивные исполнения:** засчитываем только объём, прошедший строго сквозь нашу цену (очередь на своём
   уровне не наша), и отдельно проверяем, что будет, если устаревшую котировку заберут. От этого знак итога может смениться (H6).
4. **Расчёт Up/Down 5m/15m — по Chainlink TWAP-60:** вверх, если TWAP на секунде конца ≥ TWAP на секунде начала
   (правило `chainlink-twap60`), а не по последней цене Binance.
5. **Режим рынка:** частота скачков Binance меняется в 30–60 раз (15 в час ночью и 400–900 в час днём 5 ноября).
   Отчёт всегда даём по режимам.
6. **Кластеры:** сделки одного окна или рынка зависимы, поэтому t-статистику считаем с кластерами.
7. **Data API v1 закрыт.** v2 отдаёт `limit` ≤ 1000 с курсором. Истории цен — `prices-history` CLOB, куски ≤ 14 дней.
