# ЕФБШ-649.01-АТХ — программа ПЛК ЛПЗС-5, ССЦ «Золотой початок»

Программа на Structured Text (IEC 61131-3) для контроллера Schneider Modicon **TM241CE40T**
(+ 7×TM3DI32K, 2×TM3DQ32TK по Э3), среда EcoStruxure Machine Expert (CODESYS V3).
Панель Weintek подключается по Modbus TCP.

## Состав

| Папка | Содержимое |
|---|---|
| `src/DUT` | типы данных (структуры механизма, клапана, бункера, обмена с панелью) |
| `src/GVL` | `GVL_IO` — физические каналы по Э3; `GVL_Const` — механизмы, маршруты, конфигурация; `GVL` — рабочие; `GVL_Retain` — уставки и моточасы; `GVL_HMI` — регистры панели `%MW` |
| `src/POU` | `PLC_PRG` (главная) → `PRG_Inputs` → `PRG_System` → `PRG_Topology` → `PRG_Routes` → `PRG_Mechs` → `PRG_Outputs`; ФБ `FB_Mech`, `FB_Valve`, `FB_Bunker` |
| `doc/IO_map.csv` | таблица каналов: модуль, канал, провод, переменная, сигнал, лист Э3 |
| `doc/HMI_map.md` | карта регистров Modbus для проекта панели |
| `machine_expert/` | файл импорта PLCopenXML, скрипт привязки каналов, инструкция |
| `gen/` | генераторы: `gen_io.py` (GVL_IO, PRG_Inputs/Outputs, IO_map.csv), `gen_plcopen.py`, `gen_iomap_script.py`, `gen_hmi_map.py` |
| `sim/` | симулятор ST и модель объекта для проверки логики без контроллера |

## Перенос в Machine Expert

Готовый файл для импорта — `machine_expert/EFBSH-649_PLC.xml` (Проект → Импорт PLCopenXML),
привязка каналов — скрипт `machine_expert/map_io.py`. Пошагово: `machine_expert/ИНСТРУКЦИЯ.md`.

После изменения исходников в `src/` пересобрать файлы:

```
python3 gen/gen_plcopen.py        # machine_expert/EFBSH-649_PLC.xml
python3 gen/gen_iomap_script.py   # machine_expert/map_io.py
python3 gen/gen_hmi_map.py        # doc/HMI_map.md
```

## Что проверить на объекте

Полярность датчиков собрана в константах `CFG_*` в начале `GVL_Const` (по Э3: НЗ-контакты стопов,
реле ДВУ, реле аварии ПЧ и т.д.). Если какой-то датчик на месте окажется другого типа, меняется только константа.
Скорость ПЧ задаётся местными потенциометрами (по Э3 аналоговых выходов нет), программа только пускает/останавливает ПЧ.

## Проверка логики (симулятор)

```
pip install blark==0.8.3
cd sim
python3 test_scenarios.py            # все сценарии
python3 test_scenarios.py estop      # один сценарий
```

`stsim.py` исполняет исходники `src/` как есть (разбор — blark), `plant.py` моделирует объект на уровне
физических входов/выходов по `IO_map.csv`. Сценарии: пуск и останов каждого из 11 маршрутов, порядок пуска/останова,
предпусковой сигнал, запреты одновременной работы, пауза по ДВУ и автоповтор, аварии механизмов (сбег ленты, ДКС,
ПЧ, местный «Стоп»), аварийный стоп, отключение цепи управления, отказ и потеря положения клапана, ручной режим
и наладка, местный пост, фотосепаратор, уставки с панели.
